# Упрощённый план — масштаб, цвет и соседняя текстура

Утверждён пользователем 2026-10-09; реализация и итоговые проверки продолжены 2026-10-10 после лимита. Этот план заменяет прежнее предложение PatchMatch/200%.

- [x] Ползунок 25–400%, «Вписать», горизонтальная/вертикальная прокрутка.
- [x] Зум — только состояние просмотра; координаты, история и размеры документа не меняются. Canvas рисует видимую область, а не весь увеличенный исходник.
- [x] Непрозрачная заливка, чёрный по умолчанию, системная палитра, пипетка с изображения.
- [x] Простая автоматическая текстура: найти соседний прямоугольник того же размера, сравнить известный контекст у границы, скопировать RGB, установить alpha=255.
- [x] Исключить новое выделение и все уже скрытые области из доноров и сравнения. До обработки в Worker скрытые исходные пиксели зануляются.
- [x] Предпросмотр, «Применить»/«Отмена», Escape, одна заплатка — одно действие. При ошибке предложить выбранную цветную заливку.
- [x] Worker, отмена и защита от устаревшего результата; максимум 1 миллион пикселей на заплатку.
- [x] История максимум 50 действий; пиксели заплаток хранятся отдельно по ID. Сохранять ресурсы для undo/redo; освобождать при утрате ссылок и смене изображения. Бюджет заплаток 128 MiB.
- [x] Лимиты загрузки исходного плана сохранены.
- [x] Unit и Chromium e2e: зум/прокрутка/400% инструменты/DPR1–2, цвет/пипетка, текстура/отмена/история/ресурсы, скрытые пиксели/непрозрачность, отсутствие операционных HTTP-запросов.
- [x] Экспорт PNG не добавлен; остаётся «Вечером 5».

Алгоритм не распознаёт объекты и не гарантирует, что любой незамаскированный участок семантически чист. Сложные объекты, надписи и линии могут копироваться с артефактами. Если подходящего соседнего прямоугольника нет, используется явная ошибка с предложением заливки. Оригинал остаётся в памяти для отмены; плоский экспорт и его гарантии ещё не реализованы.
